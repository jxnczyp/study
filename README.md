# 拾知 · 微信小程序错题学习系统

原生微信小程序（WXML / WXSS / JavaScript），配套 Express API 和 SQLite 数据库。已有网页版保留在 `src/`，两端共用账号、错题和学习记录。

## 微信开发者工具运行

1. 安装 Node.js 22.13 或更新版本。
2. 在项目根目录启动后端：

   ```bash
   npm install
   npm run dev:api
   ```

3. 使用微信开发者工具导入**本项目根目录**。根目录的 `project.config.json` 已设置 `miniprogramRoot` 为 `miniprogram/`。
4. 当前配置使用 `touristappid`，可用于工具支持的游客体验；如工具要求 AppID，选择测试号或填写自己的小程序 AppID。预览、真机与发布使用自己的 AppID。
5. 本机调试时，在开发者工具「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。默认后端地址为 `http://127.0.0.1:3001/api`。
6. 编译后，可以体验示例题；在「我的」中注册或登录，开始保存自己的错题和练习记录。

小程序源码位于 `miniprogram/`，不需要运行 Vite 或构建网页。`npm run dev:api` 需保持运行。

## 功能

- **学习**：学习概览、最近错题、今日复习、学习进度。
- **拍照录入**：拍照或相册选图，经已配置的第三方视觉模型转录题干，校对后保存；详情和复习均可查看原图。
- **错题本**：收录题干、答案、解析、学科、难度、知识点及出错原因；搜索、筛选、删除、标记掌握。
- **练习**：按学科、难度和题量组卷；知识变式、错题重练、即时判分、答案解析、练习成果。登录用户答错的变式题自动加入错题本。
- **我的**：账号登录 / 注册 / 退出、连续学习天数、近七天练习统计、学科掌握率、导出并分享 JSON 学习数据。登录后可复用仍有效的会话快捷进入；会记住上次邮箱，不保存密码。

当前采用**邮箱账号登录**，与已有网页账号通用；尚未接入微信一键登录。密码通过 scrypt 加盐哈希存储。小程序使用本地存储的 Bearer 会话凭证，退出后服务端撤销凭证；网页继续使用 HttpOnly Cookie。两端数据按账号隔离。

数学、物理采用规则生成数值变式；英语、语文从精选题库抽取，可能重复。出题无需接入外部 AI 服务。访客可体验练习；保存错题和练习记录需要登录。

## 整页作业检查（无标准答案）

入口：「学习 → 拍作业 · 检查错题」，或「收录 → 整页识别 · 辅助判题」。

流程：拍整页 → 选择年级/学科提示 → 确认将图片提交模型服务 → 分题识别印刷题干及手写作答 → 查看模型独立求解的参考答案、判断理由 → 校对分类和内容 → 勾选确认的错题 → 批量收录。

- 默认不选中任何题目，不会因模型判断直接保存；支持只勾选疑似错题，再人工确认。
- 正确题、疑似错题、待确认题分别显示；置信度不足、无作答/参考答案和开放性作文等归为待确认。置信度是模型自评值，不代表已验证准确率。
- 模型给出有效题目区域时，保存题目裁剪图，同时保留完整作业原图供详情页核对；区域不明确时使用整页图。区域和内容仍需校对。
- 按年级、学科、题型存储和交叉筛选；内置从幼儿园至小学、初高中、大学、研究生及成人教育的分类，支持自定义课程、年级和题型。历史题目自动归入未分类，原数据保留。
- 模型参考答案的复习采用「查看解析 → 自评」，避免按文字完全相同判断开放答案。
- 分类可覆盖所有学段和课程，**不表示模型能可靠判定所有题型**；听力缺音频、口语、作文、开放题、图文不清或无法独立求解时需要人工确认。没有标准答案无法保证判题正确率。

### 配置视觉服务

复制 `.env.example` 为 `.env`，配置：

```dotenv
VISION_API_BASE=https://api.openai.com/v1
VISION_API_KEY=你的服务端密钥
VISION_MODEL=支持图片输入及严格JSON-Schema输出的模型名称
```

然后运行 `npm run dev:api` 或 `npm start`。后端使用兼容的 `POST /chat/completions` 图片输入与 `response_format: json_object`，并在服务端提示模型遵循所需字段结构、校验返回内容。也可以配置其他兼容服务的地址。这里不预设某个模型的实际可用性，需以账号和服务支持情况为准。

密钥只存后端 `.env`，不要填写到小程序中。单题拍照转录和整页作业检查均使用配置的第三方视觉模型；未配置模型时，识别功能会提示配置错误，不会回退到本地 OCR，可手动录入。拍照识别前会提示图片将发送到模型服务。公开服务部署需按实际使用配置额度、访问频率和并发，按微信平台要求更新图片处理的隐私说明。

当前自动化覆盖兼容接口契约、分类持久化、权限、裁图、批量确认收录、重试去重及待确认降级；使用的是本地模拟视觉服务，**没有用真实模型验证手写识别或判题准确率**。部署时需对照所选服务的实际接口能力完成联调。

规则练习题库目前仍限于原有四门学科，其他课程和按年级/题型筛选的练习可使用「错题重练」；分类范围与现有规则出题范围是分别配置的。

## 拍照文字录入

进入「错题本 → 收录」，选择「拍照录入」或「相册选图」。一次处理一道题，尽量让文字清晰、光线均匀。

1. 选择图片后自动压缩并上传，服务端限制单张 8 MB，接受 JPG、PNG、WebP，并按实际图片内容校验。
2. 服务端将图片发送给已配置的视觉模型，自动转录题干和标题；题干已有文字时会询问是否替换。模型不会提供答案。
3. 校对题干、公式和选项，选择学科并补充正确答案，然后保存。**转录识别不会推断正确答案**。
4. 在错题详情或复习页点击原图查看大图。识别失败时可重试，或者保留已上传原图、手动填写题干后保存。

视觉模型必须支持图片输入和 JSON 对象输出，配置方式见上文。图片会传给所配置的第三方服务；识别结果可能不准确，特别是复杂公式、几何图形和手写内容，请以原图为准。

图片保存在 SQLite 的 `photos` 表中，接口按登录账号校验访问权限，不能通过公开 URL 访问。删除错题时会清理不再被引用的图片；未保存的草稿图片在一天后下一次上传时清理。JSON 导出包含图片引用，不含图片二进制，完整备份仍需备份数据库。图片识别受第三方模型的可用性、额度和并发限制，繁忙时可稍后重试。

相机、相册调用需要用户授权；拒绝后页面提供打开设置的入口。发布时还需在微信公众平台的用户隐私保护指引中声明所使用的选图、上传及图片处理用途，按平台要求完成配置。

## 真机调试与发布

- 修改 `miniprogram/config.js` 中的 `apiBase`。
- 真机访问时，`127.0.0.1` 指的是手机自身。局域网开发需使用电脑的局域网 IP，并让手机与电脑位于同一网络；根据开发者工具的调试方式配置域名校验。
- 正式发布前，将 API 部署到具有有效证书的 **HTTPS** 域名，并在微信公众平台配置该域名为 `request`、`uploadFile` 和 `downloadFile` 合法域名。
- 在 `project.config.json` 填入自己的小程序 AppID，通过开发者工具上传、提交审核。当前工程尚未上传或发布。
- 不要在小程序中放置 AppSecret。当前邮箱登录无需 AppSecret。

## 数据与后端

数据库默认位于 `data/study.sqlite`，可通过 `DATA_DIR` 指定目录，通过 `PORT` 指定端口（默认 3001）。数据目录已加入 `.gitignore`。备份时使用 SQLite 备份工具，或停止服务后复制整个 `data` 目录。

```bash
npm start                 # 启动 API；已构建时同时提供网页版
npm test                  # 后端集成测试，包含小程序 Bearer 会话
npm run check:miniprogram # 小程序配置、资源、请求及页面逻辑测试
```

小程序逻辑测试使用模拟的微信 API；后端图片测试使用本地模拟视觉服务验证模型调用、图片权限、关联保存与删除，不代表真实模型识别准确率。相机授权、微信原生渲染、真机拍摄和文件分享仍需在开发者工具与微信中验证。

## 可选：运行网页版

```bash
npm run dev
```

访问 http://localhost:5173 。发布网页可运行 `npm run build`，随后 `npm start`，访问 http://localhost:3001 。生产 HTTPS 部署设置 `NODE_ENV=production` 以启用网页 Secure Cookie。
